## Gemini 503 재시도 + 폴백

### TC-001: 503 에러 시 자동 재시도
- **대상:** gemini-adapter.ts `withRetry()`
- **사전 조건:** Gemini API가 503 반환하는 상태 (rate limit 초과)
- **테스트 단계:**
  1. 짧은 시간에 연속 5회 이상 분석 요청 (rate limit 유발)
  2. 503 발생 시 콘솔 로그 확인
- **기대 결과:** 최대 3회 재시도 (2초→4초→8초 대기) 후 성공 또는 폴백
- **상태:** ✅ 통과 (2026-04-09)

### TC-002: 재시도 실패 시 폴백 모델 전환
- **대상:** gemini-adapter.ts 폴백 로직
- **사전 조건:** 주 모델(lite)이 3회 재시도 후에도 503
- **테스트 단계:**
  1. TC-001에서 3회 재시도 후에도 실패 시
  2. 폴백 모델로 자동 전환되는지 확인
- **기대 결과:** 에러 없이 폴백 모델로 정상 응답
- **상태:** ⬜ 미실행 (503 지속 상황 재현 어려움)

## 작업물 히스토리 (/history)

### TC-003: 이미지 생성 시 자동 저장
- **대상:** use-image-generation.ts → artworkStorage.save()
- **사전 조건:** IndexedDB 정상 접근 가능
- **테스트 단계:**
  1. 고양이 분석 → 이미지 생성 완료
  2. /history 페이지 접속
- **기대 결과:** 방금 생성한 이미지가 갤러리에 표시됨
- **상태:** ✅ 통과 (2026-04-09)

### TC-004: 히스토리 삭제 기능
- **대상:** /history 페이지 삭제 버튼
- **테스트 단계:**
  1. 개별 항목 삭제 (hover → × 클릭)
  2. 전체 삭제 (confirm 다이얼로그)
- **기대 결과:** 삭제 후 즉시 UI 반영, IndexedDB에서도 제거
- **상태:** ✅ 통과 (2026-04-09)

## 큐비즘 프롬프트

### TC-005: B안 큐비즘 베이스 결과 확인
- **대상:** prompts.ts CUBISM_VERSION_B
- **테스트 단계:**
  1. 아무 고양이로 이미지 생성
  2. 결과물에 큐비즘 특징 확인 (면 분할, 윤곽선, 다중 시점)
- **기대 결과:** 투박하면서도 매력적인 큐비즘 스타일
- **상태:** ✅ 통과 (2026-05-07)

### TC-006: 큐비즘 이탈 방지 (curious 기질)
- **대상:** personality-mapping.ts curious + REMEMBER 앵커
- **테스트 단계:**
  1. 호기심 많은 고양이로 분석 (temperament=curious)
  2. 이미지 생성 후 결과 확인
- **기대 결과:** 초현실주의로 빠지지 않고 큐비즘 구조 유지 (각진 면 + 윤곽선)
- **상태:** ⬜ 미실행 (테스트 예정)
